# WeatherBug Growth Audit

**Live → https://eddieatadapty.github.io/weatherbug-flow-rebuild/**

Five ideas to turn more WeatherBug users into subscribers, each built into a clickable version of WeatherBug's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Show your paywall in the first launch | +10–20% CR to trial |
| 02 | Open on the search they typed | +10–20% CR to trial |
| 03 | Ask one thing, set it up before the price | +10–15% CR to trial |
| 04 | Show 2.2M ratings where they decide | +5–10% CR to trial |
| 05 | Put the saving and the free week in numbers | +5–10% ARPU |

Every price, rating and feature comes from WeatherBug's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for WeatherBug. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
